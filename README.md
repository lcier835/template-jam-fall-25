# Template for Game Dev Club at OSU's Template Jam!
### Steps
1. Download this template onto your machine
2. Open this as a godot (4.5) project
3. Play the game
4. Think of what you can add/improve/remove
5. Do it
6. Go back to step 3 until the end of the jam
7. Submit to itch.io
8. Showcase your game at the next club meeting

### Important:
- This template **requires Godot 4.5** (later version may also work)
- Your game can be in any genre
- You can remove as much of this template as you want
- You can even not use any of the template if you want (you dont even need to use Godot)
- we just ask that you make your game be at least _top down 2d
